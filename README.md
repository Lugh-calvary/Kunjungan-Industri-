# 📊 Kunjungan Industri – Bursa Efek Indonesia
## Digital Documentation of Industrial Visit

Website dokumentasi interaktif kunjungan industri ke Bursa Efek Indonesia (BEI).

---

## 📁 Daftar File (Semua dalam 1 Folder)

Semua file berada langsung di dalam satu folder tanpa subfolder:

```
Kunjungan Indusri/
├── index.html     ← Halaman utama website
├── style.css      ← File styling/CSS
├── script.js      ← File JavaScript interaktif
├── foto1.jpg      ← Display grafik investasi LED
├── foto2.jpg      ← Galeri komik edukasi investasi
├── foto3.jpg      ← Kutipan inspiratif Bill Gates
├── foto4.jpg      ← Lobby utama gedung IDX
├── foto5.jpg      ← Patung banteng (Bull) ikonik
├── foto6.jpg      ← Direktori gedung BEI
├── foto7.jpg      ← Plakat peresmian Bursa Karbon Indonesia
├── foto8.jpg      ← Trading Floor & ticker saham
├── foto9.jpg      ← Koridor galeri BEI
└── README.md      ← Dokumentasi proyek
```

---

## 🚀 Cara Membuka Website

Cukup buka / double click file `index.html` menggunakan browser apa saja (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
Pastikan perangkat terhubung internet saat pertama kali dibuka untuk memuat font & ikon dari CDN.
